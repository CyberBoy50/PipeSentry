Defensive lesson — pin actions to commit hashes.
A tag like @v4 is a mutable pointer: whoever controls the action repo can move it, and every pipeline that uses it runs the new code. A full 40-char commit SHA cannot be moved. Pin every third-party action to its SHA and keep the version as a # vX.Y.Z comment, so Dependabot can still open update PRs. In March 2025 the tj-actions/changed-files tags were rewritten to malicious code (CVE-2025-30066) and 23,000+ repos ran it — every one of them would have been safe on a SHA pin.
